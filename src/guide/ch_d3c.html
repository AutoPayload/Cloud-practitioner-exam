VPC and hybrid networking

Skim Read the “How the exam asks” table first. Read the rest only if something there surprises you.

A VPC (Virtual Private Cloud) is your own private network in a Region. You split it into subnets, one per AZ, and control traffic with route tables and firewalls. The exam asks only one or two networking questions, at a basic level.

Components

ComponentWhat it does
VPCPrivate network in one Region, defined by an IP range (CIDR).
SubnetA slice of the VPC in one AZ. Public (has a route to the internet gateway) or private.
Internet gatewayConnects the VPC to the internet.
NAT gatewayLets instances in private subnets reach the internet (for updates) while staying unreachable from outside.
Security group / NACLInstance firewall (stateful, allow only) / subnet firewall (stateless, allow and deny).
VPC Flow LogsRecord the IP traffic going in and out of network interfaces, for troubleshooting.
VPC peeringPrivate connection between two VPCs. No overlapping IP ranges. Not transitive.
VPC endpoints / PrivateLinkReach AWS services (like S3, DynamoDB) or partner services privately, without the internet.
Transit GatewayA hub that connects thousands of VPCs and on-premises networks (hub and spoke, transitive).
Site-to-Site VPNEncrypted connection to on premises over the public internet. Quick to set up.
AWS Direct ConnectA dedicated private physical line to AWS. Consistent performance. Takes weeks to set up.
AWS Client VPNConnects individual users' computers into the VPC.

IP addresses: an instance's public IPv4 changes on stop and start; an Elastic IP stays fixed. Public IPv4 addresses cost money; IPv6 is free.

How the exam asks about it

If the question saysThink
private instances need to download updatesNAT gateway
dedicated, private, consistent connection to on premisesDirect Connect
connect to on premises quickly, encrypted, over the internetSite-to-Site VPN
connect many VPCs and on-premises networks through one hubTransit Gateway
access S3 without going over the internetVPC endpoint (gateway endpoint)
capture information about IP trafficVPC Flow Logs
block one IP address at the subnetNetwork ACL
Don't confuse

VPN vs Direct Connect. VPN uses the public internet with encryption; it is ready in minutes. Direct Connect is a private cable; it is faster and more consistent but takes weeks, and it isn't encrypted by default. Internet gateway vs NAT gateway: the internet gateway allows traffic both ways; NAT allows only outbound.

Application integration

Skim Read the “How the exam asks” table first. Read the rest only if something there surprises you.

Integration services let parts of an application talk to each other without being tightly connected. That is called decoupling: if one part is slow or fails, the others keep working, and each part scales on its own.

The services

ServicePatternKey facts
Amazon SQSQueueProducers send messages, consumers poll them. Messages are kept up to 14 days (4 by default) and deleted after processing. Standard (unlimited throughput) or FIFO (strict order).
Amazon SNSPublish/subscribeOne message to many subscribers: email, SMS, mobile push, SQS, Lambda, HTTP. No storage of messages.
Amazon EventBridgeEvent busRoutes events from AWS services, SaaS partners and your apps to targets using rules. Also runs schedules (cron). Formerly CloudWatch Events.
Amazon MSKManaged KafkaManaged Apache Kafka. Pick it when a company already uses Kafka for streaming.
Amazon KinesisStreamReal-time big data streaming (clicks, IoT, logs). Amazon Data Firehose loads streams into S3, Redshift or OpenSearch.
Amazon MQManaged brokerManaged ActiveMQ or RabbitMQ for apps that use open protocols (MQTT, AMQP, STOMP) when you migrate them. You don't have to rewrite them.
AWS Step FunctionsWorkflowVisual, serverless workflows that coordinate Lambda functions and other services, with retries, branches and human approval steps.
Amazon SESEmailSend transactional and marketing email at scale.

How the exam asks about it

If the question saysThink
decouple components, buffer requests, process laterAmazon SQS
messages must be processed in exact orderSQS FIFO queue
send one notification to many subscribers, email or SMSAmazon SNS
react to events, schedule a Lambda every hourAmazon EventBridge
real-time streaming data, click streams, IoTAmazon Kinesis
migrate an app that uses RabbitMQ or ActiveMQAmazon MQ
coordinate several Lambda functions in a workflowAWS Step Functions
Don't confuse

SQS vs SNS. SQS is a queue: each message is processed once by one consumer, and it waits until someone takes it. SNS is a megaphone: every subscriber hears every message right now, and nothing is stored.

Memory hook

SQS = Queue. SNS = Notification. Kinesis = kinetic, data in motion.

Monitoring and observability

Skim Read the “How the exam asks” table first. Read the rest only if something there surprises you.

Monitoring tells you how your systems perform, who changed what, and whether AWS itself has a problem that affects you. The key skill is picking the right tool among CloudWatch, CloudTrail, Config, X-Ray and the Health Dashboard.

Amazon CloudWatch

  • Metrics: numbers over time for every service: EC2 CPU, network, status checks (every 5 minutes by default, every 1 minute with detailed monitoring). EC2 memory is not collected by default; install the CloudWatch agent.
  • Alarms: act when a metric crosses a threshold: send an SNS notification, trigger Auto Scaling, stop or reboot an instance. States: OK, ALARM, INSUFFICIENT_DATA. Billing alarms use metrics stored in us-east-1.
  • Logs: collect application and system logs from EC2 (with the agent), Lambda, ECS, CloudTrail and more.
  • Dashboards: graphs of your metrics in one view.

The other tools

ToolAnswers the question
AWS CloudTrailWho made this API call, when and from where? (audit, governance). CloudTrail Insights spots unusual activity.
AWS ConfigWhat did this resource's configuration look like over time, and is it compliant?
AWS X-RayWhere is the slow part of my distributed app? It traces requests across microservices.
AWS Health DashboardIs AWS having a problem? Service health shows public status for all Regions. Your account health (formerly Personal Health Dashboard) shows events that affect your resources, like scheduled maintenance.
Amazon EventBridgeHow do I react automatically when something happens?

CloudWatch watches performance. CloudTrail leaves a trail of footprints (who did what). Config is the configuration history. X-Ray sees inside the request path.

Deploying and managing resources

Skim Read the “How the exam asks” table first. Read the rest only if something there surprises you.

There are several ways to create resources on AWS: click in the console, type commands, write code, or describe the whole setup in a template (infrastructure as code). For anything you repeat, the exam prefers automation.

Ways to interact with AWS

  • Management Console: the web interface. Good for learning and one-time tasks.
  • AWS CLI and SDKs: scripts and code that call AWS APIs. Good for repeatable tasks.
  • AWS CloudShell: a browser terminal with the CLI already installed and your credentials loaded.
  • Infrastructure as code (IaC): templates that create the same environment every time, in any Region or account.

The services

ServiceWhat it does
AWS CloudFormationIaC with JSON or YAML templates. Creates a stack of resources in the right order; delete the stack to remove it all. Free (you pay for the resources).
AWS CDKDefine infrastructure in a programming language (TypeScript, Python, Java, .NET); it generates CloudFormation.
AWS Elastic BeanstalkPaaS: upload your code and Beanstalk creates and manages EC2, load balancing, Auto Scaling and monitoring. You only own the code.
AWS CodeCommit / CodeBuild / CodeDeploy / CodePipeline / CodeArtifactGit repositories / build and test / deploy to EC2 and on-premises servers / orchestrate CI/CD pipelines / store code dependencies (npm, pip, Maven).
AWS Systems ManagerManage fleets of EC2 and on-premises servers: patching, run commands, inventory. Session Manager gives a shell with no SSH keys and no port 22. Parameter Store holds configuration and secrets.
AWS AppConfigChange application settings and feature flags safely at run time, with gradual rollout and automatic rollback.

How the exam asks about it

If the question saysThink
provision the same infrastructure repeatedly as codeCloudFormation
define infrastructure in Python or TypeScriptAWS CDK
developers just upload code; AWS handles capacity and deploymentElastic Beanstalk
patch a fleet of servers, including on premisesSystems Manager (Patch Manager)
shell access with no SSH keys and no open portsSystems Manager Session Manager
automate build, test and deploy (CI/CD)CodePipeline (with CodeBuild and CodeDeploy)
one-time task from the browserManagement Console or CloudShell
Don't confuse

CloudFormation vs Elastic Beanstalk. CloudFormation builds any infrastructure you describe. Beanstalk builds a standard web app environment for your code. CodeDeploy vs Systems Manager: CodeDeploy deploys application versions; Systems Manager operates and patches the servers. Both work on premises too.
