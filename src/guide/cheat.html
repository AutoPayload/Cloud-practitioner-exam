Cheat sheet

The numbers, rules and one-line matches that show up again and again. If a line here surprises you, open its chapter.

Numbers to remember

  • S3 durability 11 nines (99.999999999%); S3 Standard availability 99.99%
  • S3 max object 50 TB (older questions may say 5 TB)
  • S3 minimum storage: IA 30 days · Glacier Instant/Flexible 90 · Deep Archive 180
  • Deep Archive retrieval 12–48 h; Flexible 1 min–12 h; Instant ms
  • AZs per Region: usually 3 (min 3, max 6); edge locations 400+
  • Lambda: max 15 min, up to 10 GB memory; free 1M requests/month
  • SQS retention 4 days default, 14 days max
  • CloudTrail event history 90 days; EC2 metrics every 5 min (1 min detailed)
  • RDS read replicas: up to 15
  • Spot up to 90% off; RIs / EC2 Instance SP up to 72%; Compute SP up to 66%
  • Ports: 22 SSH · 3389 RDP · 80 HTTP · 443 HTTPS
  • Exam: 65 questions, 90 min, pass 700/1,000, retake after 14 days

Shared responsibility in four lines

  • AWS: facilities, hardware, network, hypervisor, managed-service patching
  • You: data, IAM, security groups, guest OS on EC2, encryption choices, app code
  • Shared: patch management, configuration management, training
  • More managed service = less for you (EC2 → RDS → Lambda)

Security one-liners

  • Who did it? CloudTrail · How is it configured? Config
  • Threats GuardDuty · CVEs Inspector · PII in S3 Macie
  • Root cause Detective · All findings Security Hub
  • Compliance reports Artifact · Shared outside account Access Analyzer
  • DDoS Shield · SQL injection/XSS WAF · all accounts Firewall Manager
  • Keys KMS · dedicated HSM CloudHSM · TLS certs ACM · rotate passwords Secrets Manager
  • App users Cognito · employee SSO IAM Identity Center · temp creds STS
  • Explicit Deny always wins

Root-user-only tasks

  • Change account name, root email or root password
  • Close the account; restore IAM user permissions
  • Register as a Reserved Instance Marketplace seller
  • Enable S3 MFA Delete; sign up for GovCloud

Compute picks

  • Interruptible + cheapest → Spot
  • Steady 1–3 years → RI / Savings Plans; across Lambda and Fargate → Compute SP
  • Licenses per socket → Dedicated Host
  • Event code, no servers → Lambda · containers, no servers → Fargate
  • Kubernetes → EKS · simple VPS → Lightsail · just upload code → Beanstalk
  • HTTP routing → ALB · TCP/UDP, static IP → NLB · appliances → GWLB

Storage picks

  • Disk for one instance → EBS · fastest temporary → instance store
  • Shared Linux files → EFS · Windows SMB → FSx for Windows · HPC → FSx for Lustre
  • Unknown access → Intelligent-Tiering · cheapest archive → Deep Archive
  • WORM → Object Lock · undo deletes → Versioning · auto-move → Lifecycle
  • Petabytes offline → Snowball · online sync → DataSync · hybrid → Storage Gateway
  • Central backups → AWS Backup

Database picks

  • SQL, managed → RDS / Aurora · failover → Multi-AZ · more reads → read replicas
  • Key-value at scale → DynamoDB (+ DAX for µs)
  • Cache → ElastiCache · warehouse → Redshift · SQL on S3 → Athena
  • Graph → Neptune · MongoDB → DocumentDB · time series → Timestream
  • ETL → Glue · dashboards → QuickSight · Hadoop/Spark → EMR
  • Migrate a DB → DMS

Network, edge, integration, monitoring

  • Private subnet to internet → NAT gateway · private line → Direct Connect · quick encrypted → VPN
  • Many VPCs → Transit Gateway · S3 privately → VPC endpoint
  • DNS, routing policies → Route 53 · caching → CloudFront · static IPs → Global Accelerator
  • Queue → SQS · fan-out → SNS · events/cron → EventBridge · streams → Kinesis
  • Metrics and alarms → CloudWatch · tracing → X-Ray · AWS events affecting you → Health Dashboard

Billing and support picks

  • Estimate → Pricing Calculator · analyze and forecast → Cost Explorer
  • Alerts, including forecasts → Budgets · most detail → Cost and Usage Report
  • Spend spikes → Cost Anomaly Detection · right-size → Compute Optimizer
  • One bill, shared discounts → Organizations · limit accounts → SCP · landing zone → Control Tower
  • Designated TAM, <15 min → Enterprise · cheapest 24/7 phone + full Trusted Advisor → Business (now Business Support+)
  • Third-party software on your bill → Marketplace · find a partner → APN

Memory hooks

  • Six advantages: Trade, Scale, Guess, Speed, Stop, Global
  • Six pillars: SPORCS (Security, Performance, Operational excellence, Reliability, Cost, Sustainability)
  • CAF phases: Every Airplane Leaves Soon (Envision, Align, Launch, Scale)
  • CAF perspectives: BPG business side, PSO technical side
  • 7 Rs: Retire, Retain, Relocate, Rehost, Replatform, Repurchase, Refactor
  • Support response: 12 h → 1 h → 30 min → 15 min
  • DR: Backup → Pilot light → Warm standby → Multi-site (cheap and slow → costly and fast)

Exam-day checklist

  • ID ready; system test passed for an online exam; empty desk

  • Never leave a blank; flag and move on after about a minute
