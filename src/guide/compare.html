The pairs the exam loves to mix up

Compare

Most wrong answers on this exam are a real service from the right family doing the wrong job. These tables put the look-alikes side by side. Study one table at a time: cover the right column and say it out loud.

CloudWatch vs CloudTrail vs Config vs X-Ray

ServiceQuestion it answersExample
CloudWatchHow is it performing? Alert me.CPU above 80% → alarm → add instances
CloudTrailWho did what, and when?Which user deleted the S3 bucket yesterday
ConfigWhat is the configuration, and is it compliant over time?Which security groups allow SSH from anywhere
X-RayWhere is the slow part of the request?Tracing a request through five microservices

performance → CloudWatch, people and API calls → CloudTrail, settings → Config, request tracing → X-Ray.

ServiceLooks atFinds

ControlLevelKey trait
